# EleDock 1.0.1

- Fixed holding a shortcut minimizing or restoring only one window instead of repeating.
- A short press now always acts on exactly one window, even when EleDock's own settings window is in front. Pressing twice quickly acts on two windows, and releasing a held shortcut stops right away.
- Holding a shortcut keeps working when an excluded app comes to the front, and shortcut changes take effect immediately.
- EleDock now keeps a single installation: a copy with another name or in another Applications folder is replaced by “EleDock” in the Applications folder, and the extra copy is moved to the Trash.
- The website link in About now opens, Space and Help keys are shown in your language, and shortcut conflicts show a permission notice when access is not yet granted.

- 단축키를 누르고 있어도 창이 하나만 최소화·복원되고 연속 동작하지 않던 문제를 고쳤습니다.
- 짧게 한 번 누르면 EleDock 설정 창이 맨 앞에 있어도 항상 창 하나만 동작합니다. 빠르게 두 번 누르면 창 두 개가 동작하고, 누르고 있던 단축키를 떼면 바로 멈춥니다.
- 길게 누르는 중 제외한 앱이 맨 앞에 와도 연속 동작이 이어지고, 단축키 변경은 바로 적용됩니다.
- 설치본을 하나로 유지합니다. 다른 이름이거나 다른 응용 프로그램 폴더에 있는 사본은 응용 프로그램 폴더의 “EleDock”으로 바뀌고, 남는 사본은 휴지통으로 옮깁니다.
- 정보 탭의 웹사이트 링크가 열리고, Space·Help 키가 사용 언어로 표시되며, 권한이 없을 때 단축키 충돌 목록에 권한 안내가 나옵니다.

- ショートカットを押し続けても、ウインドウが1つしかしまわれず・復元されず、連続で実行されなかった問題を修正しました。
- 短く1回押したときは、EleDock の設定ウインドウが最前面にあっても、常にウインドウ1つだけに実行されます。すばやく2回押すとウインドウ2つに実行され、押し続けていたショートカットを離すとすぐに止まります。
- 押し続けている間に除外したアプリが最前面になっても連続実行が続き、ショートカットの変更はすぐに反映されます。
- インストールを1つに保ちます。別の名前や別の“アプリケーション”フォルダにあるコピーは“アプリケーション”フォルダの“EleDock”に置き換えられ、残ったコピーはゴミ箱に移されます。
- 情報タブの Web サイトリンクが開くようになり、Space・Help キーが使用言語で表示され、アクセス権がないときはショートカットの重複一覧にアクセス権の案内が表示されます。
