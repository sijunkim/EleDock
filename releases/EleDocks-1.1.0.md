# EleDocks 1.1.0

- EleDocks’s own Settings window now minimizes and restores like any other window.
- Holding the shortcut no longer stops after minimizing only the Settings window.
- A single short press no longer minimizes two windows while a window is still animating.
- A restored window no longer stays in the list of minimized windows.
- Long lists of excluded apps and conflicting shortcuts now scroll instead of being cut off.
- EleDocks can now be added to Excluded Apps like any other app.
- The installer disk now shows the EleDocks icon.

---

- EleDocks 설정 창도 다른 창처럼 최소화하고 복원합니다.
- 단축키를 길게 눌렀을 때 설정 창만 최소화하고 멈추지 않습니다.
- 창이 움직이는 도중에 짧게 한 번 눌러도 창이 두 개씩 최소화되지 않습니다.
- 복원한 창이 최소화된 창 목록에 남지 않습니다.
- 제외 앱과 단축키를 쓰는 앱 목록이 길어지면 잘리지 않고 스크롤됩니다.
- 다른 앱처럼 EleDocks도 제외 앱에 추가할 수 있습니다.
- 설치 디스크에 EleDocks 아이콘이 표시됩니다.

---

- EleDocks の設定ウインドウも、ほかのウインドウと同じようにしまったり復元したりできるようになりました。
- ショートカットを押し続けたときに、設定ウインドウだけをしまって止まらなくなりました。
- ウインドウの動きの途中で短く1回押しても、ウインドウが2つしまわれなくなりました。
- 復元したウインドウが、しまったウインドウの一覧に残らなくなりました。
- 除外アプリやショートカットを使うアプリの一覧が長くなっても切れずにスクロールするようになりました。
- ほかのアプリと同じように、EleDocks も除外アプリに追加できるようになりました。
- インストールディスクに EleDocks のアイコンが表示されるようになりました。
