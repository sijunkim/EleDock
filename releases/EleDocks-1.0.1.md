# EleDocks 1.0.1

- If the installer disk is still mounted when EleDocks launches, it offers to eject it and move the downloaded DMG file to the Trash.
- The disk image window no longer scrolls when hidden files are shown in Finder.
- "Check for Updates" no longer ends with an ellipsis.

---

- 설치 디스크가 붙어 있는 상태로 EleDocks를 실행하면 디스크를 꺼내고 내려받은 DMG 파일을 휴지통으로 옮길지 묻습니다.
- Finder에서 숨김 파일을 표시해도 디스크 이미지 창에 스크롤이 생기지 않습니다.
- "업데이트 확인" 문구에서 말줄임표를 뺐습니다.

---

- EleDocks の起動時にインストールディスクがマウントされたままの場合、ディスクを取り出し、ダウンロードした DMG ファイルをゴミ箱に入れるかどうかを確認するようになりました。
- Finder で不可視ファイルを表示しても、ディスクイメージのウインドウがスクロールしなくなりました。
- 「アップデートを確認」の末尾に省略記号が付かなくなりました。
